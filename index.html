About this video

This video demonstrates a single degree of freedom (SDOF) system, idealised as a lumped mass supported by a spring and a damper. When the mass is displaced and released, it oscillates at its natural frequency while the damper gradually removes energy, so the amplitude decays over time. The video explains how mass and stiffness set the natural period, how the damping ratio controls how quickly the motion dies out, and why the response grows sharply when the loading frequency approaches the natural frequency of the system (resonance).

What is an SDOF system?

A system whose motion can be described by a single coordinate, such as a lumped mass on a spring and damper, or a one-storey frame idealised as a mass on a flexible column.

Equation of motion

m·ü + c·u̇ + k·u = p(t)

Here m is mass, c is damping, k is stiffness, u is displacement and p(t) is the applied force.

Key properties

  • Natural frequency: ωₙ = √(k/m)
  • Damping ratio: ξ = c / (2·m·ωₙ)
  • Natural period: Tₙ = 2π / ωₙ

Response Visualizer

A damped SDOF system under harmonic loading, plotted against the frequency ratio r = ω / ωₙ. Move the sliders to see how damping changes the response.

Python Code

The Python script behind the plots: dynamic magnification factor, transmissibility ratio and phase angle for several damping ratios. Replace it with your own code, or link your repository below.

sdof_response.py 
import numpy as np
import matplotlib.pyplot as plt

# frequency ratio r = w / wn and damping ratios to compare
r = np.linspace(0, 3, 600)
damping_ratios = [0.05, 0.1, 0.2, 0.5, 1.0]


def dmf(r, xi):
    """Dynamic magnification factor Rd = u / u_static."""
    return 1 / np.sqrt((1 - r**2) ** 2 + (2 * xi * r) ** 2)


def transmissibility(r, xi):
    """Transmissibility ratio TR = transmitted force / applied force."""
    num = np.sqrt(1 + (2 * xi * r) ** 2)
    den = np.sqrt((1 - r**2) ** 2 + (2 * xi * r) ** 2)
    return num / den


def phase(r, xi):
    """Phase angle between force and displacement, in degrees."""
    return np.degrees(np.arctan2(2 * xi * r, 1 - r**2))


fig, axes = plt.subplots(1, 3, figsize=(16, 4.8))
plots = [
    (dmf, "Dynamic Magnification Factor", "Rd", (0, 5)),
    (transmissibility, "Transmissibility Ratio", "TR", (0, 5)),
    (phase, "Phase Angle", "phi (degrees)", (0, 180)),
]

for ax, (func, title, ylabel, ylim) in zip(axes, plots):
    for xi in damping_ratios:
        ax.plot(r, func(r, xi), label=f"xi = {xi}")
    ax.set_title(title)
    ax.set_xlabel("Frequency ratio r = w / wn")
    ax.set_ylabel(ylabel)
    ax.set_ylim(*ylim)
    ax.grid(True, alpha=0.3)
    ax.legend()

plt.tight_layout()
plt.show()
